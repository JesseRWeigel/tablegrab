tablegrab  

What it does

Merged cells are the whole problem. A table with colspan and rowspan is a sparse description of a grid, and CSV wants the dense one, so every merged cell is repeated into the slots it covers and a short row is padded rather than shifted. A header two or three rows deep collapses into one compound name per column: Revenue / 2023.

Numbers lose their thousands separators and currency symbols, dates become ISO, and the values that only look numeric stay text. A postcode of 07030 that comes back as 7030 is the failure this is built around, so version strings, phone numbers, part codes and anything with a leading zero are refused, and one refused value makes the whole column text.

Output is CSV, JSON, Markdown, or a CREATE TABLE and INSERT pair. No network, no dependency, nothing leaves the page.
